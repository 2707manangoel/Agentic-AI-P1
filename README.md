# Project 01 – My First n8n Workflow

## Overview
This is my first project in my 50-project journey to learn Agentic AI and workflow automation using n8n.

The workflow demonstrates how to create data, transfer information between nodes, use expressions, and make decisions using conditional logic.

## Concepts Learned
- Manual Trigger
- Edit Fields Node
- JSON Data
- Expressions in n8n
- Data Transfer Between Nodes
- IF Node and Conditional Logic

## Workflow Architecture

Manual Trigger → Edit Fields 1 → Edit Fields 2 → IF Node

## Workflow Description

1. **Manual Trigger:** Starts the workflow manually.
2. **Edit Fields 1:** Creates student and project information.
3. **Edit Fields 2:** Generates a dynamic welcome message using expressions.
4. **IF Node:** Checks whether the status equals "Learning Started".

## Technologies Used
- n8n
- Docker Desktop
- JSON
- Workflow Expressions

## How to Run
1. Install and start n8n.
2. Open the n8n workflow editor.
3. Import the provided JSON workflow.
4. Execute the workflow manually.
5. Inspect the output of each node.

## Learning Outcome
Learned the fundamentals of workflow automation, structured data, expressions, and conditional decision-making.
